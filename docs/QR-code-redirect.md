# QR Code Redirects

The QR redirect page is `qr-code-redirect.html`.

It lives at <https://etherstudios.net/projects/wywh/qr-code-redirect.html>.

This page is an intermediary page that serves as a redirect for QR codes that are printed on postcards.

In v1, all QR codes will point to this page, which will, in turn, forward users to the main WYWH website.

In v2, we can update this page to redirect visitors to a safe, shareable page
related to the postcard. Recipient addresses and other private order data must
never be available through the QR destination.
